# Universal Scraper — Frontend

Frontend for the Universal Scraper project, built with Svelte 5 + Vite.

## Run it

```
npm install
npm run dev
```

Then open the URL it prints (usually http://localhost:5173).

## Scripts

- `npm run dev` — start the dev server with hot reload
- `npm run build` — production build into `dist/`
- `npm run check` — check the Svelte code for problems (accessibility, unused CSS, etc.)

## Folders

- `src/` — the Svelte app (`pages/` for pages, `lib/` for shared components and helpers)
- `legacy/` — the original vanilla HTML/CSS/JS sign-in page, kept for reference
